# Design system

Every Help Me widget follows this spec, so any two of them look like one family on a home screen. The visual reference is Pixel's own system UI (Material 3 / Material You), with layout ideas from iOS and Samsung One UI widgets.

> The bar: it should look like Google shipped it on Pixel. Calm, precise, generous whitespace, no gimmicks. If it looks like generic AI output, it's wrong.

## Principles

1. **Glanceable first.** The one number that matters (temperature, price) is the biggest thing on the widget. Everything else is quieter.
2. **Clean rows, no scrolling.** Detail lives in a single, evenly spaced row or a short list that fits. If it doesn't fit, show less. Never scroll.
3. **Deliberate at every size.** Each span has its own layout, not a scaled or cropped version of another.
4. **Follow the system.** Wallpaper colors, light/dark, Google Sans, system corner radius. The widget should change when the system changes, instantly.
5. **Few options, all visible.** Every setting shows its effect in the live preview.

## Geometry

| Token | Value |
|---|---|
| Edge padding | 16 dp |
| Corner radius | `android.R.dimen.system_app_widget_background_radius` |
| Minimum touch target | 48 dp (glyph 20 dp, spinner 18 dp) |
| Pixel cell | ≈ 97 dp wide × 105 dp tall |
| 4×2 (the hero size) | ≈ 387 × 212 dp |
| Landscape 4×1 | ≈ 836 × 105 dp |
| Glance container limit | 10 children |

**Breakpoints** (from the size the launcher actually reports, `SizeMode.Exact`):

| Height | Width | Layout family |
|---|---|---|
| < 130 dp (1 row) | < 150 dp | Tiny: the big number only |
| < 130 dp | < 270 dp | Compact: big number + one line |
| < 130 dp | ≥ 270 dp | Strip: a horizontal row (forecast or tickers) |
| ≥ 130 dp | < 270 dp | Narrow stacked (2×2, 2×3) |
| ≥ 130 dp | ≥ 270 dp | Stacked / list (4×2 and up). Bigger sizes add detail (daily forecast, open/high/low). |

All sizes are composed at once into a sized RemoteViews map, so resizing or rotating never wakes the app.

## Anatomy of the 4×2

```
┌──────────────────────────────────────────┐
│ header (location / market status)    ⟳   │  quiet, 12-14 sp, onSurfaceVariant; refresh top-end
│                                          │
│ BIG NUMBER                  icon + label │  the glance: temperature / price
│                                 detail   │  H/L, change chip
│                                          │
│  Now   1PM   2PM   3PM   4PM   5PM       │  edge-aligned row: first and last items
│   ☀     ⛅    ⛅    ⛅    ☁     ☁        │  sit on the content edges, even steps between
│  58°   58°   58°   58°   56°   53°       │
└──────────────────────────────────────────┘
```

**Edge-aligned rows.** For N items across width W, with item content width `c = max(icon + 8, 44 dp)`: `step = (W − c) / (N − 1)`, so the first and last items align with the 16 dp content edges, like iOS and One UI.

## Color

- **Dynamic (default).** Material You colors as **color resources** (color state lists generated by `tools/gen_colors.py` → `DynRes.kt`, system M3 roles on API 34+, tonal fallbacks on API 31-33). Passed to Glance as resource-backed `ColorProvider`s, so wallpaper and dark-mode changes apply without a render.
- **Fixed palettes.** Blue, Teal, Green, Amber, Rose, Violet, Mono. Each is derived from a seed hue and chroma into light and dark schemes (`Palettes.scheme`).
- **Background tone.** Surface (default), Primary (tonal) or Secondary.
- **Theme.** System, Light or Dark per widget.
- **Opacity.** 0-100% in steps of 10, **background only**. Text, icons and chips stay fully opaque.
- **Semantic colors** (stocks). Google Finance green/red, tuned per theme for contrast. Change chips are tonal by default (solid or plain text optional). Red-up (East Asian) is an option.
- **Icons.** Weather uses Google's own weather icon set (the one Pixel Weather uses), with deepened greys on light surfaces and separate night art. A monochrome Material Symbols set follows the accent color. UI glyphs are Material Symbols Rounded, imported as vectors with `tools/import_icons.py` and `tools/svg2vector`.

## Type

Google Sans on Pixel (system default elsewhere). Hierarchy:
- Big number: light weight, very large (temperature 56-64 sp at 4×2).
- Primary text (names, prices): 16 sp, medium.
- Secondary (subtitles, labels, header): 12-14 sp, `onSurfaceVariant`.
- Numbers use tabular figures where columns must line up.

## The app (configuration only)

Compose Material 3 **Expressive** (Material3 1.5: `MaterialExpressiveTheme`, segmented list items), edge-to-edge, light and dark. `testTagsAsResourceId` is on, so UI Automator can find controls by tag.

- **Home.** A live widget preview over a wallpaper backdrop, Refresh and **Add to home screen** buttons, then the global settings (refresh interval, Wi-Fi only, units, source), Diagnostics → Logs, and a battery/hibernation hint.
- **Editor** (`ConfigActivity`, opened from the widget's Customize). Live preview on a wallpaper backdrop (so opacity is visible), then segmented groups in this order: **Content → Appearance** (Colors swatches, Theme, Background, Opacity) **→ What to show** (switches) **→ On tap** (radio list) **→ Updates and diagnostics**. Save / Cancel. It validates that the widget id belongs to the app.
- **Logs.** Plain monospace text, newest at the bottom, with **Copy** and **Clear**. 3-day retention.

Every widget's editor uses the **same labels, order and controls** for the shared options (palette, theme, background, opacity, refresh button, on tap).

## Tap behavior

| Option | Weather | Stocks |
|---|---|---|
| Default | Pixel Weather / Google weather | Yahoo Finance app (else web), as Apple's widget does |
| Also | This app, Refresh, Nothing | Google finance card, this app, Refresh, Nothing |

Rows can have their own targets (a stock row opens that stock). With no data yet, a tap refreshes. With an empty setup, a tap opens the app.

## Review checklist

Before any UI change ships, run the `widget-design-review` skill: every size, light and dark, every palette and tone, opacity 0 / 60 / 100, long names, huge and tiny numbers, empty and error states, landscape, and side by side with the sibling widget.
